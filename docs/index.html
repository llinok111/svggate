svggate

A render-verified gate for SVG optimization. It replays svgo's plugin list one plugin at a time, rasterises each step with resvg, compares it with the untouched original, and names the plugin that changed what people see.

Everything on this page was produced by the tool itself at build time — verdicts, numbers and diff images all come from gate() runs over the fixtures in the repository. Nothing here is hand-written.

The same preset, replayed over 28 real third-party SVGs that were already on the development machine. A gate that fires on everything is as useless as one that fires on nothing, so the false-positive rate is reported next to the catch rate.

summary

svggate is MIT licensed and wraps svgo (MIT) and resvg (MPL-2.0) as runtime dependencies. Known limits: system fonts are off by default, so glyph-level changes in <text> are not compared; SMIL timing is not simulated; CSS defined outside the document is invisible. See the repository README for the full list.
